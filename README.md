# caerjar.github.io

The Caerjar website, served by GitHub Pages at https://caerjar.github.io/.

Static pages, no build, no script. Shared styles in `assets/site.css`; favicon in `assets/favicon.svg`.

| Page | File | Holds |
|---|---|---|
| Home | `index.html` | Introduction and mission, what we do (Build, Advise, Teach), four featured works (Specsmith, daimon, caer-stack, Earshot), how we work, get in touch (email) |
| What we do | `offerings/index.html` | Four engagements (anchors #build, #advise, #infrastructure, #teach): who it is for, possible deliverables, related work; rates and scope |
| Work pages | `work/<slug>/` | One page per work, built by tools/build.py. No Work index: the home page features four works; the others are linked from What we do |

Style: the "Notebook" direction, after Ink & Switch (inkandswitch.com): Newsreader serif, IBM Plex Sans
labels, one reading column, a drawn line glyph per offering.

Contact is a direct `mailto:hi@caerjar.com` link; there is no form, so nothing implies a server received a message.

Copy source: `~/caerjar/drafts/website-and-tenor-2027/caerjar-website.md` (2026-11-07), including its editorial notes.

## Content

- **Mission** (Eon's words): "Caerjar's mission is to build technology that expands human and collective autonomy." Followed by "We help our clients own the tools they depend on." The first is the Home headline.
- **Offerings**: three. Care (herbal and community health) and commissions (installations, performance,
  editions) are not offered for hire on this site; that work stays on the Work page.
- **Works**: every work listed is a real work with a page on eonmeridian.github.io; its one line is
  copied from that work's `work.md` (`sub:`). Add one by copying an `<li>` in the terrain or offering.
- **Rates**: none published yet. What we do says "Rates on request" plus a sliding-scale line.

House rules from eonmeridian.github.io apply: no em-dashes, no machine-intelligence vocabulary or
vendor names, no real name. Exception (Eon, 2026-11-05): this site names "AI agent workflows" as an area of work.

## Work pages

`work/<slug>/` pages are generated by `python3 tools/build.py` from each work's own
`work.md`, the same file eonmeridian.github.io reads, so one edit updates both sites.
The list of works is `WORKS` in that script (client-facing works only; the art stays on
the portfolio). Images are copied into `assets/img/`. Rebuild after editing any work.md.
The build stops on an em-dash or a private name.
Works with no work.md elsewhere (local-models, specsmith) live in `works/<slug>.md` here; they are drafts for Eon to rewrite.
